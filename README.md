# Rutas Puebla — Sprint 1

API REST y frontend web para la administración de paradas de transporte público en la ciudad de Puebla, utilizando **FastAPI** y **Redis Cloud** con visualización en mapa mediante **Leaflet**.

## Estructura del proyecto

```text
rutas-puebla/
├── app/
│   ├── main.py
│   ├── database.py
│   ├── models.py
│   └── routes.py
├── static/
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── .env.example
├── .gitignore
├── requirements.txt
└── README.md
```
